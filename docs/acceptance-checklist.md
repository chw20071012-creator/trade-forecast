# 首次功能验收范围

状态：首版已实现；交付记录为 **124 项测试及 13 项子测试通过**，并已在真实浏览器中完成本地 UI 演示。此处的浏览器验收使用演示资料，不表示外部获客平台、真实邮箱或用户 GPT 账号已经连通。完整记录见 `VERIFICATION.zh-CN.md`，安装步骤见 `QUICKSTART.zh-CN.md`。

1. **安装和 AI 接口：已实现，Windows/GPT 待实测。** 已提供完整源码、Windows 安装/启动/停止脚本、临时 HTTPS 隧道脚本、Bearer 鉴权与 Actions schema；Linux 本地运行和权限边界已检查。Windows 实机、实际隧道和用户 GPT 账号的端到端连接未验证，其他 AI 的连接取决于其工具支持。
2. **资料导入：离线验证通过。** 客户、箱包、茶叶及用户提供的采购成本可从 XLSX/CSV 导入，保留字段与来源；补充附件可保存，提取后核对，缺失值不变成零。用户真实文件仍需在导入时核实。两个空白 Excel 模板不含虚构价格或官方数据。
3. **市场分析：导入与演示验证通过，在线平台未接通。** 已实现统计口径校验、金额单位、HS 前导零、可比期间增长、市场证据和国家选择；Comtrade 有限预览适配已实现，官方站点实时访问仍受本云环境网络限制。演示统计不是实际行情。
4. **客户开发：采集与状态逻辑离线验证通过，真实 Maps 探测失败并暂停。** 支持大小企业及小商户、去重、来源追溯、分段查询和后续线索。真实 Google Maps 有限探测返回 `paused_search_error`，错误为 `net::ERR_TUNNEL_CONNECTION_FAILED`，未取得可用于宣称成功获客的真实结果。展会、官网和搜索按实际网络核实；名单导入可作替代，不宣称覆盖全部现实客户。
5. **邮件与 WhatsApp：审批和执行保护离线验证通过，无真实发送。** 已实现逐封定制证据、完整批量审核、版本/附件绑定、间隔、额度、异常暂停、未知结果核对及防重复。间隔和真实发送分支使用受控测试验证，演示只模拟。WhatsApp 生成消息和聊天链接，手动状态按用户确认记录，不作为平台送达验证。
6. **询盘与报价：逻辑验证通过，Gmail 授权未配置。** Gmail 读取、外贸邮件候选识别与待核对记录已实现，候选识别不是最终事实确认。利润规则提出/确认、真实毛利率与完整成本计算已验证；实际报价仍需用户上传或录入真实采购、规格、数量、汇率和履约成本。
7. **订单到复购：离线和 UI 演示验证通过。** 合同草稿、生产、出运单据、物流、收款、售后及复购记录已实现；进度提取先待用户确认，付款声明不自动作为到账。草稿文件生成与单据一致性核验已检查；未执行正式签约、真实付款或出运。
8. **可靠性：离线验证通过。** 备份/恢复、文件路径与认证资料边界、操作记录、失败状态保存及用户指令任务已检查。恢复不自动重跑发送；备份默认不包含 API key 或 Gmail token。未授权账号、网络不可用和未核实平台规则单独报告，不用演示通过替代真实接入。
