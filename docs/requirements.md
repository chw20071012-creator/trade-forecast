# 外贸程序需求记录

更新时间：2026-10-11。主要需求访谈已完成，首版已实现并完成离线及浏览器演示验证；以下已确认事项作为交付与首次真实使用的依据。

## 已确认

- 同时支持箱包 OEM 和茶叶 B2B，共用客户和订单基础能力，业务规则分别配置。
- 单人使用；目标电脑为 Windows。
- 交付可复制、可迁移的程序源码，也应能为其他支持工具调用的 AI 提供接口。
- 第 30 问已答 A：交付完整可迁移程序文件夹，包含源码、导入模板、Windows 安装/启动脚本，以及 ChatGPT Actions 连接配置和使用说明；不要求主体源码严格单文件。
- 第 31 问已答 B：先使用明确标注的演示资料验证程序功能，后续导入用户真实资料。演示不作为真实获客、真实行情或邮箱账号接通的证据。
- 首先对接 ChatGPT Plus，用户在 ChatGPT 聊天中下指令调用程序。
- 第 22 问已答 A：用户实际账户能创建自定义 GPT，并看到 Actions（操作）设置。首版已提供 Bearer 鉴权、Actions schema、GPT Instructions 和临时 HTTPS 隧道连接脚本；Windows 部署、实际隧道及用户 GPT 账号的端到端调用仍需在目标电脑验证。
- 只按用户指令执行，不定时运行。
- Google Workspace 企业邮箱。
- 第 27 问已答 C：允许读取整个企业邮箱，自动识别外贸询盘、客户回复及跟进事项；同步由用户指令触发。此读取范围不改变已确认的邮件发送审核规则。
- 邮件先生成草稿，用户确认后由程序发送。生成草稿、确认内容、发送状态必须分别记录。
- 第 26 问已答 B：展示本批客户名单和每封完整邮件，用户勾选后一次确认发送；确认绑定所选收件人、草稿版本与附件，变化后需重新确认。
- 每封开发信均须按该客户的实际业务、采购角色、产品适配和可核实信息单独定制，不仅替换称呼。无可靠客户信息时保留资料缺项，不编造采购记录、痛点或产品认证。
- 用户要求发送前查适用软件的账号限制/发送规则，邮件间隔发送，避免触发限制。需区分平台邮件/收件人限额与 API 请求配额；间隔和个性化降低风险但不能保证账号不受限。
- 发送队列保存进度并可暂停/续发，限额不足、退信异常、账户警告或不确定发送结果时暂停相应任务并核实；不靠换账号或反复重试突破限制。间隔属于用户启动的本次任务，不新增定时获客。
- 第 24 问已答 B：首版通过邮箱与 WhatsApp 触达客户。LinkedIn 继续作为负责人发现来源，未选为首版发送渠道。
- 第 25 问已答 A：AI 生成 WhatsApp 消息及聊天链接，用户打开后点击发送。首版不依赖 WhatsApp 商业发送 API；已提供手动确认打开、发送和回复状态的记录接口，结果标为用户报告，不作为平台送达证明。
- 用户处于业务初始化阶段，但已有几份客户名单和产品目录。
- 第 28 问已答：用户委托选择便于 AI 阅读的格式。结构化客户、产品及采购资料主格式采用 Excel（.xlsx），同时支持 CSV；一行一条记录、第一行固定字段、避免合并单元格。现有文件的原始格式尚未逐份核实，PDF、Word、图片等保留为补充资料，并提供转录/核对入口。
- 空白导入模板已生成：`templates/trade-data-template.xlsx`，包含说明、客户名单、箱包产品及茶叶产品四个工作表，无虚构样例或价格。
- 核心需求：自动发现、整理、筛选和开发客户；结合行情提供报价建议。

- 程序先分析各国市场机会，由用户选定目标国家后再开发客户。

- 最低利润率由程序根据成本与可比行情提出建议，用户确认后采用；第 18 问已答，不重复要求用户先给固定比例。

- 地图搜索按用户选定国家，再按城市/地区、产品与商户类型分段，保存已搜索范围及待续线索；不承诺搜索结果穷尽所有现实客户。低优先级但符合业务的客户保留在待开发队列，未知利润或联系方式的客户标记待核实。
- 用户指定官方市场统计来源：中国海关总署统计平台、UN Comtrade、美国 USITC DataWeb、Eurostat、韩国贸易统计；中国海关选出口、美元、商品编码及贸易伙伴维度。
- 官方汇总统计用于国家/HS/时期层面的市场分析，不被当作公司级交易记录或联系人数据库。
- 联系人数据工具由开发方案按需选择；用户愿意提供所需账号，无法提供时采用替代方案。不得据此要求所有平台注册或把账号状态当作已授权 API。
- 第 20 问已答：客户搜索、联系人查询及邮箱验证先采用免费方案，当前付费预算为 0；用户愿意以后按需要提高预算，具体费用另行讨论。此意向不等于已授权购买订阅或付费调用。

## 行情定价的设计约束

- 行情证据保留来源、采集日期、币种、单位、规格、数量阶梯和贸易条款。
- 箱包按材质、尺寸、工艺、配件、数量、定制和包装匹配可比商品。
- 茶叶按品类、等级、产地、检测/认证、批次、包装、数量匹配可比商品。
- 采购成本、检测包装、运费、汇率、账期和利润底线需要可更新的真实输入。
- 零售价、采购挂牌价、成交价、出口报价应分别标识，不能直接混用。
- 缺实际成本时仅给有依据的参考区间与待补数据，不输出保证最优、保证盈利的价格。
- 已发现的询盘 skill 的建议利润百分比只是模板，不能自动成为用户的利润规则。
